# LLM Behavioral Evolution

Research project investigating behavioral evolution, inter-agent influence, and alignment stability in fine-tuned Large Language Models.

## Research Objective

To investigate whether LLMs with contrasting behavioral objectives influence each other's behavior through repeated interactions, and whether behavioral changes are temporary or persistent.

## Experimental Models

- **Good LLM:** A model fine-tuned for helpfulness, honesty, cooperation, and safe behavior.
- **Adversarial LLM:** A model exhibiting controlled adversarial behavioral tendencies in a sandboxed research environment.
- **Baseline LLM:** The original pretrained model used as a comparison.

## Research Areas

- LLM fine-tuning
- Behavioral alignment
- Multi-agent interaction
- Behavioral drift
- Human-AI interaction
- AI safety evaluation
